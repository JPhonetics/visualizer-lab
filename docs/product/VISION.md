# Visualizer Lab — Product Vision

## Purpose

Visualizer Lab is a learning-focused application for making code behavior easier to understand visually.

It should not become merely another online code editor.

The value of the product is the combination of:
- editable code
- rendered or executed output
- controls that isolate behavior
- visual explanations of what the code is doing

## Initial product area

The first visualizer is the Frontend Visualizer.

It will eventually let a learner:
- edit HTML
- edit CSS
- edit JavaScript
- see the rendered result
- disable CSS
- disable JavaScript
- reload execution
- change responsive viewport size
- zoom the presentation
- open a standalone Visualized view
- save work
- load templates
- export/import projects
- share projects

## Future visualizers

Planned candidates:
- JavaScript
- Python
- SQL

JavaScript and Python should eventually visualize execution, not only display console output.

Possible visualization concepts include:
- variables
- arrays/lists
- objects/dictionaries
- loops
- scope
- call stack
- function calls
- recursion
- data structures
- algorithms
- execution steps

## Product principles

- learning-first
- visually understandable
- predictable controls
- minimal unnecessary complexity
- modular architecture
- local-first where practical
- portable user work
- accessible UI
- useful without requiring an account
