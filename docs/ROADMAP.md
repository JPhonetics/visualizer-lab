# Visualizer Lab — Roadmap

Active work: Phase 3 Real Frontend Editor on feature/frontend-editor. Foundation,
testing and Pages preparation are merged; Pages publication succeeded, while
certificate provisioning/HTTPS production sign-off remains an open external task.

## Phase 1 — Frontend Foundation
Shell, Sidebar, Editor/Preview layout, resize/collapse behavior, theme, Preview controls, Visualized page, routing, selector, SPA fallback, UI cleanup, lint/build.

## Phase 1.5 — Testing Foundation
Vitest, React Testing Library, meaningful unit/component tests, Playwright, E2E smoke test, CI validation.

## Phase 2 — Deployment Pipeline
GitHub Pages, custom domain, HTTPS, production route verification, GitHub Actions build/deploy, pull-request CI.

## Phase 3 — Real Frontend Editor
CodeMirror, HTML/CSS/JavaScript editors, editor state ownership, tests.

## Phase 4 — Live Preview
Editor state to preview document, CSS/JS toggles, debouncing/update strategy, iframe isolation, reload behavior, integration/E2E tests.

## Phase 5 — Local Projects
Current Work, Saved Work, naming, local-first project model, IndexedDB or appropriate storage, stored-data migration/version strategy.

## Phase 6 — Templates
Template format, starter templates, template loading, overwrite/confirmation behavior.

## Phase 7 — Portability and Sharing
Export/import, versioned project format, compact share URL where practical, validation/security of imported data, optional cloud share IDs later.

## Phase 8 — Frontend Learning Features
Richer Help/Format behavior and visual explanations of HTML/CSS/JavaScript relationships.

## Phase 9 — JavaScript Visualizer
Editor/runtime, Run/Step/Reset, console, variable state, arrays/objects, scope, call stack, function calls, visual sharing/export.

## Phase 10 — Python Visualizer
Python runtime strategy, Run/Step/Reset, console, variables, lists/dictionaries, loops, functions, stack/scope, visual sharing/export.

## Phase 11 — Deep Learning Visualizations
Recursion, data structures, algorithms, execution timeline, references, teaching/export modes.

## Optional later phase — Cloud
Accounts, synced projects, public/private cloud shares, backend persistence only if product needs justify it.
